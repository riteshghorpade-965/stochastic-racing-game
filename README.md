# 🏎️ Stochastic Racing Game

A Python-based AI project demonstrating **Stochastic Games using a Randomized Game Tree and Expected Utility**.

## 📌 Problem Statement

**Stochastic Games – Randomized Game Tree**

Create a game tree containing random/chance nodes and calculate expected utility.

## 🎯 Objective

The objective of this project is to demonstrate decision-making under uncertainty using:

- MAX / Player decision nodes
- CHANCE / Random nodes
- Probability of different outcomes
- Utility values
- Expected Utility calculation
- Randomized outcome selection

## 🧠 AI Concept

This project uses a **Stochastic Game** concept.

The basic decision process is:

```text
MAX / PLAYER
     ↓
FAST or SAFE
     ↓
CHANCE NODE
     ↓
Random Outcome
     ↓
Probability + Utility
     ↓
Expected Utility
     ↓
Score Update
